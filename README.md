# Smart System Club – Candidate Shortlist Announcement

A modern and responsive web application developed for the **Smart System Club** to officially announce the shortlisted candidates for the Developer Recruitment process.

The website presents the shortlist through an elegant user interface with smooth animations, responsive layouts, and a structured candidate announcement experience.

---

## 📌 Overview

The Smart System Club Candidate Shortlist Announcement website was created to provide a professional platform for announcing the candidates shortlisted for the next stage of the Developer Recruitment process.

The project focuses on creating a clean, engaging, and responsive experience that reflects the professionalism of the club.

---

## ✨ Features

- Official candidate shortlist announcement
- Professional and modern user interface
- Fully responsive design
- Smooth page transitions and animations
- Candidate assessment workflow
- Interactive shortlist reveal
- Congratulations screen for shortlisted candidates
- Optimized for desktop, tablet, and mobile devices

---

## 🛠️ Built With

- React.js
- Vite
- HTML5
- CSS3
- JavaScript (ES6)

---

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/AbhiCodeX99/Smart-System-Club.git
```

Navigate to the project directory

```bash
cd Smart-System-Club
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
